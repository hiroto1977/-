# UI 表示言語ルール

Service Hub は日本語利用者向けの業務ダッシュボードです。ダッシュボード、サイドバー、設定画面、
各サービスページ、通知、エラー、空状態を含むユーザー向け表示は日本語を標準にします。

## 必須ルール

1. **ユーザーに見える文言は日本語で書く**
   - 見出し、ボタン、フォームラベル、説明文、カード、表のヘッダー、空状態、エラー、トースト、ツールチップを含みます。
   - スクリーンリーダーで読み上げられる `aria-label` / `title` も同じ扱いです。
2. **サイドバーは日本語補足を必須にする**
   - `src/renderer/services.ts` の `description` は必ず日本語を含めます。
   - `label` は正式サービス名を除き日本語にします。
3. **英字だけの仮置き表示を残さない**
   - `Dashboard`, `Settings`, `Loading`, `Coming soon`, `Submit` のような英語プレースホルダーは不可です。
   - 必要なら「ダッシュボード」「設定」「読み込み中」「準備中」「送信」のように置き換えます。
4. **専門用語は日本語の文脈で補足する**
   - API / KPI / URL / OAuth / CSV などの標準略語は許容します。
   - ただし「CSV 出力」「OAuth API 連携」のように、操作や意味が日本語で分かる文にします。

## 許容される例外

- GitHub、Slack、YouTube、Docker などの正式なプロダクト名・ブランド名。
- API、KPI、BEP、URL、CSV、CI など、国内業務UIでも一般的な略語。
- コード識別子、ファイルパス、URL、HTTPメソッド、コマンド、ログ、外部APIから返る原文データ。

例外を使う場合も、周辺の説明や操作文は日本語で書きます。

## チェック方法

```bash
npm run lint:ui-copy
npm run verify:all
```

`lint:ui-copy` はサイドバー定義を検査し、正式サービス名として許可されていない英字だけのラベルや、
日本語を含まない説明文を検出します。新しいサービス名を正式名称として残す必要がある場合は、
`scripts/lint-ui-copy.cjs` の許可リストへ理由が分かる形で追加してください。
