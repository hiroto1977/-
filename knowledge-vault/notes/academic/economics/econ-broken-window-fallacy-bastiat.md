# 割れ窓の誤謬（バスティア）——「見えるもの」と「見えざるもの」

> [!info] コレクション: [[学術概念]] ・ 区分: 経済学 ・ asOf: 2026-06-27 ・ 出典: 2件（うち権威ある出典 ✓）

## 概要
割れ窓の誤謬（broken window fallacy、ガラス屋の誤謬）は、フランスの経済学者・思想家フレデリック・バスティアが1850年の論考「見えるものと見えざるもの（That Which Is Seen and That Which Is Not Seen）」の冒頭で示した、経済をめぐる根強い誤りを暴く寓話である。ある少年が店の窓ガラスを割ってしまう。集まった人々は、やがて「むしろ良いことだ」と慰める。割れた窓を直すためにガラス屋が六フランを稼ぎ、そのガラス屋がまた別の誰かにお金を使い……と需要が連鎖して経済が回るではないか、と。バスティアはこの推論を厳しく批判する。たしかにガラス屋が六フランを得るのは「見えるもの（ce qui se voit）」である。しかし「見えざるもの（ce qui ne se voit pas）」がある。もし窓が割れていなければ、店主はその六フランで靴を買うなり本を買うなりできたはずで、靴屋なり本屋なりの商売がそれだけ潤ったはずである。窓の破壊は、店主が新たな富（靴や本）を得る機会を奪い、ただ元の状態（窓のある状態）に戻すために資源を費やさせたにすぎない。社会全体では、靴一足分だけ豊かになり損ねている。破壊は決して純益を生まない。バスティアの核心は、経済を論じる者は、目に見える直接の効果（ガラス屋の利益）だけでなく、目に見えない、起こらなかった代替的な使い道（機会費用）まで勘定に入れねばならない、という点にある。良い経済学者と悪い経済学者を分けるのは、まさにこの「見えざるもの」を見通す力である。同じ論考でバスティアは、解雇された兵士、増税、公共事業、保護関税など十二の例に同じ論理を当てはめた。この寓話は、機会費用の概念、戦争や災害が経済を刺激するという俗説（破壊神話）への反証、ケインズ的な穴掘り公共事業をめぐる論争の格好の教材として、今日まで経済教育で繰り返し参照される、経済学的思考の出発点である。なお、同名の隠喩を用いる犯罪学の「割れ窓理論」（ウィルソンとケリング）とは、まったく別個の議論である。
