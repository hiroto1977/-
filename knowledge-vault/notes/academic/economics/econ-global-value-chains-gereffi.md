# グローバル・バリューチェーン（ゲレッフィ）

> [!info] コレクション: [[学術概念]] ・ 区分: 経済学 ・ asOf: 2026-06-26 ・ 出典: 4件（うち権威ある出典 ✓）

## 概要
グローバル・バリューチェーン（global value chains; GVC）は、ゲレッフィ＆コーゼニウィッツ（1994）が国際産業組織論の枠組みとして提唱した、特定の商品・サービスが原材料から最終消費者に届くまでに複数国を越えて行われる生産・流通の連鎖を分析する概念である。GVCガバナンス論では、先導企業（lead firm）が標準設定・認証・設計を通じてサプライヤーを指揮する「バイヤー主導型」と、技術・資本の提供者がバリューチェーンを制御する「生産者主導型」の二形態を区別した。ポンティセッリ他（2008）のGVC分析は、付加価値の地理的分布が特定の「アップグレード」経路——プロセス・製品・機能・部門間——に沿って発展するかを実証した。COVID-19パンデミック・米中貿易摩擦・半導体不足は「サプライチェーン強靱化（supply chain resilience）」・「フレンドショアリング（friendshoring）」・「ニアショアリング（nearshoring）」論議を加速させ、GVC地理の再編が進んでいる。
