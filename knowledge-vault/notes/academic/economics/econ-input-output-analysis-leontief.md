# 投入産出分析——レオンチェフ・マトリクスと産業連関の定量的分析

> [!info] コレクション: [[学術概念]] ・ 区分: 経済学 ・ asOf: 2026-06-26 ・ 出典: 3件（うち権威ある出典 ✓）

## 概要
ワシリー・レオンチェフが1941年に開発した投入産出分析は、経済の各産業部門が互いにどれだけの財・サービスを「投入」し「産出」するかを行列（投入係数行列）で表し、最終需要の変化が全産業に与える波及効果を定量的に算出するフレームワークである。基本モデルは「産出量 ＝ 中間投入需要 ＋ 最終需要」という線形恒等式から導かれ、レオンチェフ逆行列（I - A）⁻¹が各部門への需要乗数を与える。米国・日本・国連（SNA）の産業連関表がこの枠組みに基づいており、GDP推計・環境負荷分析（CO2排出の産業別配分）・サプライチェーン脆弱性評価に広く用いられる。拡張版の「環境産業連関分析」はカーボンフットプリントの国際比較に利用され、温暖化対策の費用効果分析に応用されている。レオンチェフは1973年にノーベル経済学賞を受賞した。
