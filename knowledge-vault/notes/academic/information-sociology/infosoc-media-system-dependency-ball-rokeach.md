# メディア・システム依存理論——メディアへの依存が効果の強さを規定する

> [!info] コレクション: [[学術概念]] ・ 区分: 情報社会学 ・ asOf: 2026-06-27 ・ 出典: 2件（うち権威ある出典 ✓）

## 概要
メディア・システム依存理論（media system dependency theory、MSD）は、コミュニケーション研究者サンドラ・ボール＝ロキーチとメルヴィン・デフルーが1976年に提唱した、マスメディアの効果に関する理論である。それまでのメディア効果論が、メディアが受け手に直接強い影響を与えるとする「強力効果論」と、受け手の選択性ゆえに効果は限定的だとする「限定効果論」の間で揺れていたのに対し、MSD理論は、効果の強弱が生じる「条件」を、個人・メディア・社会システムの三者の関係から説明しようとした。中心となる考え方は、人々が自らの目標を達成するためにメディアという情報資源にどれだけ「依存（dependency）」しているか、によってメディアの影響力が決まる、というものである。人は、（1）周囲の世界を理解する（理解、understanding）、（2）どう行動すべきかを判断する（方向づけ、orientation）、（3）緊張を解きほぐし楽しむ（遊び、play）、といった目標を持つ。これらの目標達成のために必要な情報を、メディアが独占的・中心的に供給しているほど、人々のメディアへの依存は強まり、それに伴ってメディアが認知・感情・行動に及ぼす効果も大きくなる。重要なのは、この依存の強さが社会状況に左右される点である。社会が安定し変化が乏しいときには、人々のメディア依存は相対的に低い。しかし、災害・戦争・経済危機・急速な社会変動など、不確実性や葛藤が高まる状況では、人々は何が起きているのかを理解し、どう行動すべきかを知るために、いっそうメディアに頼らざるをえなくなる。その結果、そうした時期にはメディアの影響力が飛躍的に増大する。MSD理論はこのように、メディアの効果を、受け手の能動性（依存の動機）と、社会システムの状態（安定か変動か）と、メディアシステムの中心性という、複数の水準の相互関係のなかに位置づけた。エリフ・カッツらの「利用と満足」研究が受け手の能動的なメディア利用に注目したのと響き合いつつ、MSD理論はそれを社会構造的な条件と結びつけた点に独自性がある。メディア・システム依存理論は、メディア効果の大きさが固定的ではなく、社会的文脈と人々の依存関係に応じて変動することを示した、メディア社会学の重要な理論的枠組みである。
