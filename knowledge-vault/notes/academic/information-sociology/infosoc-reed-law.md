# リードの法則——グループ形成ネットワークの指数関数的価値

> [!info] コレクション: [[学術概念]] ・ 区分: 情報社会学 ・ asOf: 2026-06-27 ・ 出典: 2件（うち権威ある出典 ✓）

## 概要
リードの法則（Reed's law）は、計算機科学者デビッド・P・リードが1999年の論考「あの忍び寄る指数関数——メトカーフの法則を超えて、コミュニティ形成の力へ」で提唱した、ネットワークの価値の規模に関する主張で、人々が集団（サブグループ）を作れるネットワークの価値は、参加者数 N に対して指数関数的（2のN乗）に伸びうる、とするものである。リードは、ネットワークの価値の伸び方を三つの段階で整理した。第一はサーノフの法則で、放送のような一方向（一対多）のネットワークでは、価値は視聴者数 N に比例する。第二はメトカーフの法則で、利用者どうしが二者間でつながるネットワークでは、つなぎ方の数（N×（N−1）／2）に応じて価値は N の二乗に比例する。第三がリードの法則で、利用者が自由に小集団・コミュニティを作れる「グループ形成ネットワーク（GFN）」では、作りうる部分集合の数が 2のN乗からNと1を引いた数にのぼり、これは指数関数的に増えて、やがてどんな多項式（NやNの二乗）をも圧倒する。リードは、ネットワークの主たる価値が、放送（視聴）から取引（二者間）へ、さらに集団への帰属へと移るにつれて、支配的な項が N から N の二乗へ、さらに 2のN乗 へと移り変わる、と論じた。だから社会的ネットワークでは、集団形成がもたらす価値が最後にはすべてを呑み込む、というのである。この法則は、オンライン・コミュニティやソーシャルメディア、プラットフォームの爆発的な価値を説明する論拠として引かれてきた。一方で批判もある。アンドリュー・オドリツコらは、すべての集団やつながりが等しく価値をもつわけではなく、2のN乗はもちろん N の二乗ですら過大評価で、価値はむしろ N×log（N）に近いと論じた。リードの法則は、文字どおりの予測式というより、集団形成がもつ潜在的な力を質的に示す「上限」として読むのが妥当とされる、ネットワーク理論の概念である。
