# 競合価値観フレームワーク——組織文化の4類型と有効性基準

> [!info] コレクション: [[学術概念]] ・ 区分: 経営学 ・ asOf: 2026-06-26 ・ 出典: 3件（うち権威ある出典 ✓）

## 概要
競合価値観フレームワーク（Competing Values Framework, CVF）は、クインとロルボー（1983）が組織有効性の基準を統合的に分類するために開発した二次元・四象限モデルであり、組織文化・リーダーシップ・人材管理の研究と実践に広く適用されている。2つの次元は「柔軟性vs統制」と「内部志向vs外部志向」であり、これにより4つの組織文化類型が導出される。クラン（家族）文化は柔軟性・内部志向で協調・メンタリング・チームワークを重視し、アドホクラシー文化は柔軟性・外部志向で革新・起業家精神・適応性を重視する。ヒエラルキー文化は統制・内部志向で効率性・手続き・安定性を重視し、マーケット文化は統制・外部志向で競争力・成果・顧客志向を重視する。キャメロンとクイン（2006）は組織文化評価尺度（OCAI）を開発し、文化プロフィールの診断と変革に応用した。ハーテルとアシュカナシー（2011）のメタ分析はCVFの組織パフォーマンスへの予測妥当性を確認しつつ、4類型の境界の曖昧さと文化的多元性の把握の限界を指摘した。
