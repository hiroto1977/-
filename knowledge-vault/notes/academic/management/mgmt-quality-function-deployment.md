# 品質機能展開（QFD・品質の家／Quality Function Deployment）——顧客の声を技術特性へ翻訳する品質計画手法

> [!info] コレクション: [[学術概念]] ・ 区分: 経営学 ・ asOf: 2026-06-27 ・ 出典: 3件（うち権威ある出典 ✓）

## 概要
品質機能展開（QFD：Quality Function Deployment）は、顧客の声（要求品質）を、製品やサービスの技術特性・設計・工程・生産管理へ体系的に翻訳していく品質計画の手法である。1966年ごろの日本で赤尾洋二と水野滋らによって考案され、初期はブリヂストンタイヤ久留米工場や三菱重工業神戸造船所での品質保証活動の中で実務化された。赤尾の最初の論文は1972年に専門誌『標準化と品質管理』に発表され、1978年の水野・赤尾編による最初の書籍を機に日本国内へ普及、その後アメリカの自動車・電機産業に広がった。中核となる図表が「品質の家（House of Quality）」で、左に顧客の要求品質を行として並べ、上に技術特性（エンジニアリング特性）を列として置き、両者がどれだけ関連するかを中央のマトリクスで評価する。屋根にあたる三角形の相関行列で技術特性どうしのトレードオフ（一方を上げると他方が下がる関係など）を示し、要求品質の重要度や競合比較も加味して、顧客満足に最も効く技術特性へ開発資源を集中させる。複数の表を連鎖させ、要求品質から部品・工程・製造の管理項目まで一貫して展開できる点が特徴である。批判・限界としては、大規模なマトリクスの作成に多大な時間と専門知識を要すること、関連度や重要度の評価が主観的になりやすいこと、顧客の声の収集が不十分だと展開全体が誤った方向を向くことなどが指摘されており、近年は数理モデルやデータ分析との併用で補強する試みが進んでいる。
